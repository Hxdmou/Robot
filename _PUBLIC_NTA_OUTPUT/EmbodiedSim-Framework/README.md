# EmbodiedSim-Framework

> **End-to-End Embodied Intelligence Simulation & Deployment Toolkit**  
> 具身智能仿真与工程部署全栈框架 · PyBullet仿真环境 · 模块化系统架构 · 工程化部署流水线  
> *（去算法实现版 · 专注仿真系统集成与工程落地应用）*

---

## ✨ 项目特色

| 模块 | 功能亮点 | 对应能力展示 |
|------|---------|-------------|
| 🎯 **仿真环境** | PyBullet通用机械臂仿真（Franka Panda / KUKA iiwa）、场景快速搭建、可视化交互 | 物理仿真环境搭建能力 |
| 🏗️ **系统架构** | 感知-决策-执行三层解耦、模块化接口设计、可插拔组件 | 系统架构设计能力 |
| 🚀 **工程部署** | 三级健康检查、部署流水线、日志审计、配置管理 | 工程化部署落地能力 |
| 🔌 **通信适配** | 多协议适配器抽象层（TCP/UDP/CAN/EtherCAT/ROS）、真机对接接口 | 多协议通信集成能力 |
| 🛡️ **安全框架** | 碰撞检测、紧急停止、异常熔断、输入校验、日志审计 | 企业级安全防护能力 |
| 🎮 **GUI控制** | Tkinter图形控制面板、实时状态监控、手动遥操作演示 | 应用界面开发能力 |
| 🧠 **AI决策接入** | 大模型决策SDK、多智能体协作编排、知识库问答接口 | AI智能体应用能力 |
| 🔄 **Sim2Real** | 域随机化框架（摩擦/阻尼/质量/温度等参数分布）、仿真到真机适配层 | Sim2Real工程迁移能力 |

## 🚀 快速开始

### 1. 环境安装

```bash
# 推荐 Python 3.10+
pip install -r requirements.txt
```

### 2. 运行仿真演示

```bash
cd examples
python run_simulation_demo.py
```

### 3. 打开GUI控制面板

```bash
cd applications
python robot_control_gui.py
```

### 4. 执行部署健康检查

```bash
cd examples
python deploy_health_check_demo.py
```

## 🧠 设计理念（去算法版）

> **本项目专注「具身智能系统工程化落地」，不包含以下纯算法实现内容：**
> - ❌ 强化学习算法（PPO/SAC/TD3/DDPG等策略网络训练）
> - ❌ 运动学逆解雅可比矩阵推导、RRT/A*路径规划算法源码
> - ❌ 数学公式推导与学术论文实验对比代码

**本项目专注展示：**
- ✅ **系统集成能力** — 如何把仿真、AI、部署、通信、安全整合成一个可用的系统
- ✅ **工程架构能力** — 三层接口解耦、模块化设计、可插拔组件设计模式
- ✅ **落地部署能力** — 真机对接健康检查、配置管理、日志审计、异常容灾
- ✅ **应用开发能力** — GUI交互、AI决策接入、数字孪生可视化
